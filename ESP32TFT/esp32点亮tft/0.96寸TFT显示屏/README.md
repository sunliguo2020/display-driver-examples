### 0.96寸TFT显示屏高清IPS LCD液晶屏幕
控制芯片：ST7735S
分辨率：80*160
裸屏（焊接/插接）、8针模组
接口类型：4线SPI
显示颜色：全彩
工作电压：3.3V

| NO.  |      SYMBOL      |
| :--: | :--------------: |
|  1   |  LEDA BLK 背光   |
|  2   |       GND        |
|  3   |  RESET RES 复位  |
|  4   | RS DC 数据命令脚 |
|  5   |       SDA        |
|  6   |       SCL        |
|  7   |   VDD VCC 电源   |
|  8   |        CS        |



## Arduino 示例

8 针插接模组的 Arduino + TFT_eSPI 示例（含接线表和 ESP32 配置）见 [Arduino_TFT_eSPI](Arduino_TFT_eSPI/README.md)。
